# KORA Dashboard

React + Vite + TypeScript. Карта (Leaflet + OpenStreetMap, безкоштовно, без ключів), статус об'єктів, графік нахилу (Recharts) та попередження. Дані оновлюються кожні 15 с.

## Запуск

Потрібен Node.js 20+ і запущений бекенд ([NASA_Hakathon_Backend](https://github.com/kora-student-project/NASA_Hakathon_Backend)).

```bash
npm install
cp .env.example .env     # VITE_API_URL=http://localhost:8000
npm run dev
```

Відкрийте <http://localhost:5173>. У `CORS_ORIGINS` бекенду має бути ця адреса.

## Продуктивність карти

- Шари NASA (схильність до зсувів, звіти COOLR) запитують дані із запасом 50% навколо видимої ділянки й **не перезавантажуються**, поки карта не вийде за цей запас або не зміниться масштаб; запити стримуються (debounce 350–400 мс), стара картинка лишається на екрані, поки вантажиться нова.
- Маркери звітів про зсуви малюються на одному `<canvas>`, а не сотнях SVG-вузлів.
- Найсвіжіший проліт NISAR шукається паралельно (по 6 днів), шар не вантажить порожні тайли, поки дата невідома.
- `preconnect` до серверів карт і API (`index.html`), `updateWhenZooming=false` для тайлових шарів.

## Збірка для продакшену

Продакшн-збірка вимагає `VITE_API_URL` з адресою `https://…` (інакше `npm run build` завершиться помилкою, щоб не ходити на `localhost` і не передавати ключ відкритим текстом):

```bash
VITE_API_URL=https://your-backend.onrender.com npm run build
```

## Мова

Перемикач **EN / UA** у шапці. За замовчуванням англійська, вибір зберігається в браузері (`localStorage`). Переклади в `src/i18n.tsx`: щоб додати рядок чи мову, доповніть словник `dict`. Тексти попереджень (`message`) приходять з бекенду англійською.

## Що показує

- **Карта:** вибір **типу карти** (випадаючий список, вибір пам'ятається): вулиці (OpenStreetMap), супутникова та гібрид із підписами (Esri World Imagery), топографічна, тіньовий рельєф, світла й темна (Esri). Усі безкоштовні, без ключів; налаштування в `src/basemaps.ts`. Далі:  маркери об’єктів і точки супутникового зміщення, кольори яких відповідають рівням порогів. Шар NASA COOLR показує історичні звіти, а [NASA Global Landslide Susceptibility](https://gis.earthdata.nasa.gov/portal/rest/services/Landslides/Global_Landslide_Susceptibility/ImageServer) показує регіональні класи схильності від 0 до 5.
- **Панель об’єкта:** статус із бекенду, нахил X/Y, температура, вологість і кількість активних попереджень. Панель супутника показує зміщення, пороги API, доступні спостереження та активні супутникові попередження.
- **Радарна карта NISAR:** шар `NISAR radar map` із NASA GIBS (NISAR L2 GCOV, радіолокаційне розсіювання, хибні кольори): щоденні тайли з вибором дати та кнопкою «Latest pass here», яка шукає останній проліт над вибраним об'єктом. Це радарна яскравість, а не карта зміщення: зміщення показують точки з `/api/satellite/map`.
- **Історія датчика:** нахил X/Y і сирі осі X/Y/Z з `extra.accel` та `extra.gyro`, якщо запис їх містить. За вибраний період завантажується до 500 вимірювань.
- **Оновлення даних:** джерела опитуються незалежно. Після збою на екрані залишаються останні отримані дані з позначкою та часом запиту. Причина статусу будівлі показує активне попередження відповідного рівня.
- **Попередження** з фільтром за рівнем. Кнопка «Вирішено» працює після введення admin-ключа у верхньому полі. Ключ зберігається лише в пам'яті сторінки (не в localStorage і не в збірці).

## Деплой на Vercel (free)

1. Vercel → Add New Project → імпортуйте репозиторій.
2. Framework — Vite (визначиться автоматично), Root Directory залишити порожнім.
3. Environment Variable: `VITE_API_URL` = адреса бекенду на Render (без слеша в кінці).
4. Після деплою додайте адресу Vercel у `CORS_ORIGINS` бекенду на Render і перезапустіть його.

> Усе, що в змінних `VITE_*`, потрапляє у публічну збірку. Не кладіть туди секрети.
